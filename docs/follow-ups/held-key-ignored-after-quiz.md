# 퀴즈가 닫힌 뒤 계속 누르고 있던 방향키가 먹히지 않는다

**Symptom**: 방향키를 누른 채 버섯에 닿아 퀴즈가 뜨고, 키를 계속 누른 상태로 퀴즈를 풀어 대화상자가 닫혀도 캐릭터가 움직이지 않는다. 키를 떼었다가 다시 눌러야 걷는다.

**Observed evidence**: `game/math-run/stage.tsx`의 키 핸들러는 월드 상태가 `running`이 아니면 keydown과 keyup을 모두 버린다(75번째 줄). 퀴즈가 시작될 때 입력은 모두 초기화된다(61번째 줄). 코드 리뷰(`code-review low`)에서 지적됐고, 브라우저에서 직접 재현하지는 않았다.

**Suspected cause**: 퀴즈 중 들어온 keydown을 무시하고 입력을 초기화하기 때문에, 퀴즈가 닫힌 시점에 어떤 키가 눌려 있는지 알 수 없다. 추정이며 확인하지 않았다.

**What was tried**: 해결을 시도하지 않았다. 인수 기준을 깨지 않고 움직임이 멈추는 것뿐이라 이번 범위에서는 그대로 두었다.

**Proposed next step**: 키 상태를 `running` 여부와 상관없이 따로 기록해 두고, 퀴즈가 닫힐 때 현재 눌려 있는 키로 입력을 복원한다. 브라우저에서 키를 누른 채 퀴즈를 풀어 걷기가 이어지는지 확인한다.
