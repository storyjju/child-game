# 퀴즈 형식

## Decisions

- 버섯 퀴즈는 보기 네 개 중 정답 하나를 고르는 방식입니다. 과목이 달라도 같은 방식과 같은 퀴즈 창을 씁니다.
- 영어 퀴즈는 영어 단어를 보여 주고 알맞은 한국어 뜻을 고르게 합니다.
- 영어 단어는 초등 저학년 기초 단어(동물, 과일, 색깔, 숫자 등)를 게임 안에 넣어 두고 무작위로 뽑습니다.
- 틀렸을 때의 규칙은 [no-penalty-play](no-penalty-play.md)를 따릅니다.

## Why

과목마다 고르는 방식이 같으면 아이가 규칙을 새로 배울 필요가 없고, 새 과목도 같은 퀴즈 창으로 넣을 수 있습니다. 영어를 아직 못 읽는 어린 아이도 부모님이 단어를 읽어 주면 함께 풀 수 있도록, 읽기 부담이 작은 "영어 → 한국어 뜻" 방향을 골랐습니다.

## Still-rejected alternatives

- 한국어 뜻을 보고 영어 단어를 고르는 방식 — 철자를 읽어야 해서 5살에게는 어렵습니다. 대상 연령이 올라가거나 난이도 단계를 도입할 때 다시 검토합니다.
