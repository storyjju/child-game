# 아이 사진 처리

## Decisions

- 아이가 올린 얼굴 사진은 브라우저 안에서만 처리합니다. 서버나 외부 서비스로 보내지 않습니다.
- 사진과 그로 만든 캐릭터는 저장하지 않습니다. 새로고침하거나 창을 닫으면 사라지고, 다음 판에서 다시 올립니다.

## Boundaries

- 현재 범위에는 계정, 서버 저장, 기기 간 공유가 없다는 전제에서 정한 결정입니다.
- 사진을 저장하거나 서버로 보내는 기능을 허용하지 않습니다. 그런 기능이 필요해지면 이 결정을 먼저 다시 엽니다.

## Why

아이 사진은 한 번 밖으로 나가면 되돌리기 어려운 민감한 정보입니다. 서버에 올리면 보관, 삭제, 보호자 동의 같은 별도 문제가 생깁니다. 사진이 기기 밖으로 나가지 않는다는 점은 부모님이 사진을 올릴 때 믿을 수 있는 근거가 됩니다. 매번 사진을 다시 올려야 하는 불편은 한 번 하고 끝나는 판에서는 작습니다.

## Reconsider when

- 캐릭터를 다음 방문에도 이어서 쓰고 싶다는 요구가 반복해서 나올 때
- 계정이나 서버 저장이 제품 범위에 들어올 때

## Still-rejected alternatives

- 서버에 사진을 올려 보관하는 방식 — 보관, 삭제, 보호자 동의 부담이 생기고 되돌리기 어렵습니다. 계정과 저장이 범위에 들어올 때 다시 검토합니다.
